## 1. 디자인 시안 분석과 보존 전략 → [01_design_inventory.md](01_design_inventory.md)

- 시안은 **화면 13종 + 홈 탭 4개 + 시트·오버레이 18종**. 장면 보드 26개는 모두 Main을 특정 상태로 여는 래퍼다.
- 기본 색 토큰 24개(라이트/다크) + 철학자 6명×4색, 글꼴 2종(Gothic A1·고운바탕), 크기표·둥글기·애니메이션을 원본값으로 표로 옮겼다 → Compose 테마에 1:1.
- 문구는 한국어·영어 각 537키, 키 집합이 똑같다 → strings.xml로 기계 변환.
- 보존: 원본은 `legacy-design-reference/`에 읽기 전용으로. 저장소가 **공개**라서 초상 6장은 Git에서 뺐다(카뮈·시오랑 사용권 미확인).
- **한계**: 캔버스 실행 파일(`support.js`)이 ZIP에 없어 이 PC에서 시안을 화면으로 띄울 수 없다 → 기준 스크린샷은 7번 결정 사항.

## 2. 요구사항 누락·불일치 점검 → [03_requirements_gap_checklist.md](03_requirements_gap_checklist.md)

중요한 것만:
- **충돌 1건**: 첫 검증 철학자 — 설계서는 니체·시오랑, 지시서는 니체·쇼펜하우어 → 지시서 우선, **니체·쇼펜하우어**.
- **시안의 버그 후보 확인됨**: 언어를 바꾸면 방·노트·기억이 **전부 초기화**된다(2곳). AI 응답 언어를 바꾸면 방별 언어 설정을 덮어쓴다. 실제 앱에서는 회귀 테스트로 막는다.
- **시안에 동작이 없는 핵심 기능**: 철학자가 먼저 말 거는 기능은 *보내는 로직이 없다*(화면과 시드 메시지 하나뿐). 자동 댓글은 '지금 받기' 버튼으로만 게시된다. 둘 다 Sprint 4에서 처음 만든다.
- 시안 데이터는 노트를 `day: 13` 같은 **날짜 숫자**로 들고 있다. 같은 날 노트 3개는 id가 달라 괜찮지만, 기억 출처가 '10월 12일 노트'처럼 날짜로만 가리켜 같은 날 노트를 구별 못 한다 → note_id로 바꾼다.
- 시안에 없어 **최소 추가 화면 승인이 필요할 수 있는 것** 4개: 모델 미설치/오류 상태, 위기 신호 안내, 감상평 여러 개, 사유 노트 읽기 범위.

## 4. 로컬 AI 검증 절차 → [ADR-002](../decisions/ADR-002-local-llm.md)

- 런타임 2개 비교: **llama.cpp**(GGUF, 모델 폭 넓음) vs **LiteRT-LM**(Google 공식 Kotlin API, MediaPipe LLM은 유지보수 모드로 넘어감).
- 모델 후보: **Qwen3 1.7B/4B**(Apache 2.0), **Gemma 4 E2B/E4B**(Apache 2.0, 2026-04 공개), Gemma 3n. EXAONE·Kanana는 배포 라이선스가 맞지 않아 제외.
- 한국어 철학 대화를 휴대폰에서 비교한 공개 자료는 찾지 못했다 → 설계서 평가 문장 13개×한/영으로 **직접 잰다**: 로드 시간, 첫 글자까지, 초당 토큰, 메모리, 발열, 취소, 그리고 사람이 읽는 품질(말투 구별, 상대 발언 받기, 지어내지 않기).
- 이 PC의 Ollama(qwen2.5:7b)로 프롬프트를 먼저 다듬을 수 있다. 단 그건 **실기기 측정이 아니다**.
