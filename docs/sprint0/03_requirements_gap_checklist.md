## C. 최근 확정 요구(Philosopher Registry) 점검

| 항목 | 시안 | 조치 |
|---|---|---|
| 안정 ID | ❌ 단축 ID `so/ni/…` | `socrates/nietzsche/…` + `legacy_ids` |
| 별칭(ko/en) | ✅ `aliases` 한 배열 | 언어별로 분리 |
| 말투·성향 | 🟡 `style` 한 문장 + `dmHello` | `persona.*` 구조화 |
| 지식·출처·권리 | 🟡 `sources` 자유 문장 | `knowledge.sources[].rights`, `quote_policy` |
| 관계 | 🟡 엔진 `PAIR` 8쌍(대사) | `relations[]` |
| 표시 순서·초상·색 | 코드 하드코딩(`ORDER`, `IMG`, CSS) | `order`, `assets.portrait`, `colors` |
| 활성/비활성 | ❌ | `status` |
| 버전 | ❌ | `pack_version`, `schema_version` |
| 추가 통합 테스트(지시서 4.4) | ❌ | 테스트용 가짜 철학자 팩 `test_philosopher` 등록 → 개인톡·방·멘션·노트 댓글·사유 노트·선제 대상·ko/en·비활성화가 **기능 코드 수정 없이** 동작하는지 |

## D. 시안이 다루지 않아 '최소 추가 화면' 승인이 필요할 수 있는 것
- 로컬 모델 **미설치/미지원/오류** 상태의 대화방 표시 (지시서 9.3: 시연 문장으로 대체 금지)
- 위기 신호 대응 안내
- 노트 감상평 여러 개 목록(시안은 노트당 1개)
- 사유 노트 읽기 범위 설정
→ 모두 **기존 컴포넌트 문법만 재사용**한 최소안으로 만들어 승인받는다.
