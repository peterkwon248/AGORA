# Claude Code 전달용 AGORA 개발 패키지

## 우선 읽을 문서
1. `AGORA_Integrated_Development_Directive_v1.0.md` — 반드시 먼저 읽을 실행 지시서. 제품 요구사항 v2.1 원문이 부록으로 통합돼 있습니다.
2. `AGORA_design_draft.zip` — **사용자가 승인한 최신 기존 디자인 원본**. 내부 `README.md`, `canvas/project/Main.dc.html`, `Map.dc.html`, `Grammar.dc.html`, `assets/agora.css`, `assets/js/*.js`를 차례로 확인하세요. 새 디자인을 만들지 말고 기존 시안을 실제 앱으로 이식합니다.
3. `AGORA_Integrated_Master_Blueprint_v2.1.md` — 원본 제품 명세서를 개별 파일로도 수록했습니다. 실행 지시서 부록에 동일한 내용이 있습니다.

## 첫 단계
실제 Android 로컬 AI + 니체/쇼펜하우어 공통 대화 엔진 + 기존 디자인 기반 화면 이식의 Sprint 0을 실행합니다. 디자인 변경은 사전 승인이 필요합니다. 최신 추가 요구사항인 Philosopher Registry를 반드시 먼저 추상화해 둡니다.

**주의:** 디자인 ZIP의 `.dc.html`은 Claude 디자인 캔버스 전용 자료이며 배포 가능한 Android 앱 프로젝트가 아닙니다. 사전 작성된 시연 메시지 코드와 실제 AI 생성/영구 저장을 혼동하지 마세요.
