# MEMORY — 오래 유지되는 결정·선호·제약

## 사장님 선호
- 모든 보고·답변은 **한국어**. 비개발자 — '이제 무엇이 된다' 중심, 숫자는 '무엇 중 몇'.
- 가능한 건 전부 Claude가 직접. 넘기는 건 결제·계정·실물 기기·눈으로만 되는 판정.
- 저장소는 **공개 유지**(2026-10-14). 정식 출시 때 비공개 전환은 사장님이 결정.

## 확정된 결정
- 첫 검증 철학자는 **니체·쇼펜하우어** (설계서 26장의 니체·시오랑과 충돌 → 지시서 우선).
- 기술: Android Native Kotlin + Compose, 도메인은 순수 Kotlin 모듈 (ADR-001 제안, 실기기 후 확정).
- 버전: AGP 9.4.1 · Kotlin 2.4.21 · Gradle 9.8.1 · Compose BOM 2026.09.00 · compileSdk 37 / targetSdk 36 / minSdk 28(임시).
- 철학자 색은 팩 `display.colors`에 시안 원본값, 로더가 대비 4.5:1 검사.
- 1글자 별칭(`니`)은 자동완성 검색에만, 직접 입력 자동 바인딩은 2글자 이상.
- 시스템 알림 문장은 저장하지 않고 화면에서 만든다(언어 전환 대비).
- 디버그 빌드만 PC Ollama 연결(`adapters:ollama-dev`), 화면에 '개발용' 띠. 릴리스엔 인터넷 권한 없음.
- **제품 방향(ADR-010, 2026-10-14 사장님 결정)**: 철학자 중심. 평행자아는 보류(폐기 아님). 첫 버전은 시안 철학자 6명. 피드형 확장은 채택하되 화면은 Claude Design 시안 → 차이 표 → 승인 후. 이 피드는 기기 안 1인 피드이지 공개 커뮤니티가 아니다.
- 팩에 `persona.topic_affinity`(시안 REL 순위 → `(6-순위)/6`)와 `persona.examples`(말투 예시, 앱이 만든 문장) — 새 철학자 팩도 같이 채운다.
- PASS(침묵) 지시는 프롬프트에 한 번만. 두 번 말하면 작은 모델이 거의 늘 침묵한다(PC 시험 근거).
- **리디자인(ADR-011, 2026-10-15 사장님 결정)**: 하단 탭은 프로필·채팅·피드·노트. 광장 방과 '광장'이라는 말은 없앤다. 설정은 탭 위 톱니로. 노트 탭은 내가 쓴 글만, 철학자의 사유 노트는 피드로. 채팅 홈 기본은 A '말 걸기 먼저'(설정에서 A~E 고르기, 몇 개 남길지는 대기). 철학자 이미지는 사용자가 바꿀 수 있고 기기 밖으로 나가지 않는다.
- **나에 대해·같이 읽기(ADR-012)**: MD·TXT 자료를 대목으로 나눠 대목마다 참고 범위. 대화 한 턴에 첫 화자만, 대목 하나만 참고하고 '참고' 표시를 단다. 기억 후보는 사용자가 확인한 것만. 파일 속 바람은 명령으로 따르지 않고 설정을 바꿀지 묻는다. 피드에 쓰지 않고 기기 밖으로 보내지 않는다. 방 자료는 그 방 철학자만 읽는다. 철학자별 서재는 ADR-002 뒤로 미루고, 철학자 성격·말투를 바꾸는 파일은 만들지 않는다.
- 화면을 바꿀 때 기준은 리디자인 차이 표(`docs/design/REDESIGN-DIFF.md`). ✅만 옮기고 🟡·↩︎는 승인 대기. 색은 원래 '어스름' 값 추천.

## 제약
- 시안 `legacy-design-reference/` 읽기 전용. 초상 이미지는 Git 제외(카뮈·시오랑 사용권 미확인).
- 모델 가중치·글꼴·외부 소스 다운로드는 사장님 승인 후.
- 시연 문장으로 실제 AI를 흉내 내지 않는다. 모델이 없으면 '없다'고 표시.
- PC(Ollama) 결과를 실기기 측정으로 보고하지 않는다.
- 써 보기 보드(`design/redesign/`)의 예시 문장·기억 후보·대목 고르기 규칙·예시 인물 '지우'는 시안용이다. 앱으로 옮기지 않는다.
- 캔버스(Claude Design) 게시는 Artifact 게시 도구가 있는 세션에서만. 게시 전에 캔버스의 지금 파일을 읽고 비교한다(안 읽으면 게시가 거부된다).
