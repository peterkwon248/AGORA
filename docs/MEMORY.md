# MEMORY — 오래 유지되는 결정·선호·제약

## 사장님 선호
- 모든 보고·답변은 **한국어**. 비개발자 — '이제 무엇이 된다' 중심, 숫자는 '무엇 중 몇'.
- 가능한 건 전부 Claude가 직접. 넘기는 건 결제·계정·실물 기기·눈으로만 되는 판정.
- 저장소는 **공개 유지**(2026-10-14). 정식 출시 때 비공개 전환은 사장님이 결정.

## 확정된 결정
- 첫 검증 철학자는 **니체·쇼펜하우어** (설계서 26장의 니체·시오랑과 충돌 → 지시서 우선).
- 기술: Android Native Kotlin + Compose, 도메인은 순수 Kotlin 모듈 (ADR-001 제안, 실기기 후 확정).
- 버전: AGP 9.4.1 · Kotlin 2.4.21 · Gradle 9.8.1 · Compose BOM 2026.09.00 · compileSdk 37 / targetSdk 36 / minSdk 28(임시).
- 철학자 색은 팩 `display.colors`에 시안 원본값, 로더가 대비 4.5:1 검사.
- 1글자 별칭(`니`)은 자동완성 검색에만, 직접 입력 자동 바인딩은 2글자 이상.
- 시스템 알림 문장은 저장하지 않고 화면에서 만든다(언어 전환 대비).
- 디버그 빌드만 PC Ollama 연결(`adapters:ollama-dev`), 화면에 '개발용' 띠. 릴리스엔 인터넷 권한 없음.

## 제약
