# ADR-011 · 리디자인 — 탭·채팅 홈·프로필·피드 구조

- 상태: **확정(Accepted) — 아래 '결정' 1~6만**. 사장님 결정, 2026-10-14~15 (claude.ai 대화). 나머지 화면 배치는 [차이 표](../design/REDESIGN-DIFF.md)의 🟡로 남아 있고, 승인 전에는 옮기지 않는다.
- 날짜: 2026-10-15
- 관련: AGENTS.md 절대 규칙('새 디자인 금지 → 차이 표 → 승인'), ADR-010(피드형 채택), [ADR-012](ADR-012-user-materials.md)(나에 대해·같이 읽기), 캔버스 사본 [`design/redesign/`](../../design/redesign/README.md)

## 맥락
ADR-010에서 피드형 확장을 채택하고 'Claude Design 시안 → 차이 표 → 승인 → 이식' 순서를 정했다. 2026-10-14~15에 Claude Design 캔버스 'AGORA 리디자인'에서 화면 구조를 다시 짰고(v41), 앱 전체를 눌러 볼 수 있는 '써 보기' 보드도 만들었다. 색·글꼴은 '어스름' 토큰을 그대로 썼다(달라진 값 몇 개는 차이 표 0장, 원래 값 유지 추천). 바뀐 것은 정보 구조와 흐름이다.

## 결정 (사장님 확정)
1. **하단 탭 4개를 프로필 · 채팅 · 피드 · 노트 순서로 한다.** (이전 시안: 채팅 · 노트 · 철학자 · 설정)
   - 고정 광장 방과 '광장'이라는 말을 화면에서 없앤다.
   - 설정은 탭에서 빠지고, 각 탭 위 톱니 버튼으로 연다.
2. **프로필 탭**: 철학자 프로필을 친구 목록처럼 모아 보고, 맨 위에 내 프로필(꾸미기·설정)이 있다.
3. **노트 탭은 내가 쓴 글만**(직접 쓴 노트·대화 노트). 철학자의 사유 노트는 **피드**로 옮긴다. 설계서 v2.1의 '노트 탭 안 사유 노트'보다 이 결정이 우선한다.
4. **채팅 홈 기본은 A '말 걸기 먼저'.**
   - 맨 위에 말을 쓰면 어울리는 철학자를 제안한다.
   - 같은 사람들과의 방이 있으면 그 방에서 이어지고, 원하면 새로 따로 연다.
   - 설정 › 채팅 홈 모양에서 A~E(말 걸기 먼저 / 한 줄 말 걸기 / 목록 먼저 / 한 마디 띠 / 묶음 목록) 중 고른다. 예전 안 A('지금이 먼저')·C('응접실')는 지금의 A로 합쳤다.
   - 화면 표시는 A~E. 써 보기 원본의 내부 키(B·G·D·E·F)는 만든 순서대로 붙인 이름이라 다르다(`proto/logic.js`의 `HOME_LETTER`).
   - 실제 앱에 몇 개를 남길지는 승인 대기(추천: A·C 둘, 많아도 셋 — 모양마다 고칠 곳과 검사가 늘어난다).
5. **철학자 이미지는 사용자가 바꿀 수 있다.**
   - 설정 › 철학자 이미지, 또는 철학자 프로필의 카메라 배지에서 연다.
   - 앨범·카메라로 고르고, 동그라미 안에 끌기·확대·회전으로 맞춘 뒤 적용한다. 되돌리기가 된다.
   - 고른 이미지는 기기 밖으로 나가지 않는다. 앱 기본 초상은 지금처럼 흑백 필터.
6. **새 기능 두 가지**('나에 대해', '같이 읽기')는 [ADR-012](ADR-012-user-materials.md)에 따로 적는다.

## 승인 대기 (차이 표 🟡·↩︎)
- 설정 묶음
- 내 프로필 항목 구성
- 새 대화 만들기에서 '대화 분위기' 단계를 앞에서 빼는 것
- 답 순서(앱 전체 한 번에 한 명 — 기기 안 AI 실측 후)
- 방 정보 배치
- 노트 상세(여백 메모)
- 피드 아침판 배치
- 철학자 프로필 배치
- 데스크톱 4화면
- 처음 안내·모델·Plus 비교
- 채팅 홈을 몇 개 남길지
- 색 값 차이(추천: 원래 '어스름' 값)

## 근거
- 탭 순서·광장 제거·노트/피드 분리·프로필 탭·채팅 홈·철학자 이미지는 모두 사장님이 대화에서 직접 정했다.
- 채팅 홈을 여러 모양 중 고르게 하자는 것도 사장님 제안이다. A·C를 A로 합치는 것도 사장님이 허락했다("중복되는 느낌이라면 하나로 퉁쳐도 되고").
- 써 보기 보드는 상태 1,220가지를 자동으로 눌러 보는 점검을 통과했다(한/영 × 라이트/다크, 오류 0). 눈으로 보는 확인은 하지 않았다.
