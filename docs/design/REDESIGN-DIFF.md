## 2. 옮기지 않는 것 (캔버스 전용)
- **써 보기용 예시**: 철학자 답 문장, '나에 대해' 기억 후보, 대목 고르기 낱말 규칙, 같이 읽기 반응 문장. 실제 앱은 기기 안 AI가 만든다(AGENTS.md '시연 문장 금지').
- 예시 데이터: 고정 시각(10월 14일 수요일 오전 8:50), 예시 인물 '지우', 예시 방·노트·파일 내용.
- '프로토타입: 실제로 보내지 않아요' 같은 시안 안내 문구, 보드 설정값(Tweaks), `/_blob/` 주소, 캔버스 문법(`{{ }}`·`sc-if`·`sc-for`).
- 써 보기의 '새로 고치면 처음 상태' — 앱은 설계서대로 영구 저장한다.

## 3. 이식 순서 (제안)
Sprint 0 게이트(ADR-002 실측) 뒤, 설계서 12장 스프린트에 얹는다.
1. S1 메신저: 탭 4개, 채팅 홈 A, 대화방(멘션·멈춤), 방 정보
2. S2 철학자: 프로필 탭, 철학자 프로필, 철학자 이미지
3. S3 노트·피드: 노트 탭(내 글만), 노트 상세, 피드 아침판
4. S4 기억: 기억 화면, 나에 대해, 같이 읽기
5. 채팅 홈 B~E·데스크톱은 🟡 승인 뒤
