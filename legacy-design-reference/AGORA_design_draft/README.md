# AGORA 디자인 초안 · 어스름

철학자 AI들과 자유롭게 이야기하는 메신저 **AGORA**의 디자인 초안이에요.
Claude 디자인 캔버스 **'AGORA 디자인 초안'**의 원본 파일과 이미지, 스크립트, 설계서를 한데 묶었어요. (2026-10-13 기준, 통합 설계서 v2.1 반영)

## 보는 방법

- `.dc.html` 파일은 **Claude 디자인 캔버스 형식**이에요. 캔버스가 제공하는 실행 파일(`./support.js`) 위에서 돌아가기 때문에, 브라우저로 바로 열면 화면 대신 `{{…}}` 같은 틀만 보여요.
- 실제로 눌러 보려면 Claude 디자인 캔버스 'AGORA 디자인 초안'에서 여세요.
- 다른 캔버스로 옮길 때는 `assets/`의 파일을 그 캔버스에 올린 뒤, 아래 **자산 주소표**를 보고 `/_blob/…` 주소를 새 주소로 바꾸면 돼요.

## 구조 한눈에

- **Main.dc.html**이 앱 전체예요. 화면 마크업은 이 파일 안에 있고, 동작은 `assets/js`의 스크립트 네 개를 순서대로 불러와 연결해요.
- **장면별 보드 26개**는 `<dc-import name="Main" start="대화 노트">`처럼 Main을 불러와 시작 장면만 정해요. 그래서 Main을 고치면 모든 보드에 함께 반영돼요.
- **화면 설정(Tweaks)**: 언어(한국어/English), 테마(시스템/라이트/다크), 시작 화면, 오프라인 상태, 답하는 속도를 바꿀 수 있어요.

## 노트 — 설계서 v2.1에 맞춘 부분

- **이름**: 탭은 `노트`, 안에 `나의 노트`와 `철학자의 사유 노트`. 나의 노트는 `직접 쓴 노트`와 `대화 노트` 두 종류이고, 댓글은 `노트 댓글`, 내 해석은 `나의 감상평`이에요.
- **하루 여러 노트**: 날짜는 묶음일 뿐이에요. 10월 13일에는 설계서 21.5의 예시대로 노트 세 개(아침 ‘빗속에서 만난 유재하’, 점심 ‘성취와 삶의 의미’, 밤 ‘오늘 떠오른 질문’)가 따로 있어요. 유형 필터(전체 / 직접 쓴 노트 / 대화 노트)와 주간 달력으로 걸러 봐요.
- **새 노트**: 누를 때마다 새 노트예요. 제목·본문을 쓰는 동안 그 노트에만 임시 저장되고, 아무것도 안 쓰고 나가면 만들어지지 않아요. 표시 날짜를 지난날로 바꿀 수 있고, 고치면 같은 노트의 새 버전으로 남아요(수정 기록).
- **대화 노트**: ‘노트로 정리하기’는 늘 새 노트를 만들어요. 메시지를 눌러 ‘여기부터 노트로 정리’로 범위를 고를 수도 있어요. ‘새 노트로 다시 요약’도 원래 노트를 덮지 않고 새 노트를 만들어요.
- **노트마다 읽기와 댓글**: 읽을 수 있는 철학자, 자동 댓글(끔·가끔·적극적), 댓글 알림을 노트마다 정해요. 기본값은 설정 › 기억과 노트에 있어요.
- **자동 댓글 예약**: 기기 안 AI가 미리 써 두고 예약해요. 노트를 고치면 다시 확인하고, ‘나만’으로 바꾸거나 자동 댓글을 끄면 그 노트의 예약만 취소돼요(수용 시나리오 I). ‘왜 예약됐나요?’에서 근거와 올리기 직전 확인 항목을 볼 수 있어요.

## 디자인 요약 — 어스름

| | 낮 (라이트) | 밤 (다크) |
|---|---|---|
| 배경 / 카드 | `#F5F4F9` / `#FFFFFF` | `#131315` / `#1C1C1F` (색기 없는 흑연색) |
| 글자 | `#1C1930` | `#ECECEF` |
| 내 말풍선 | `#4636CC` 남색 | `#3A3A40` 차분한 회색 |
| 강조 | `#4636CC` | `#E2E2E6` (밝은 회색) |
| 등불(말하는 중) | `#F2B544` 호박색 | `#F5C25C` 호박색 |

- 철학자마다 이름 색과 초상 테두리 색이 달라요(소크라테스·니체·쇼펜하우어·카뮈·시오랑·아우렐리우스). 낮·밤 모두 글자 대비 4.5:1 이상이에요.
- 글꼴: **Gothic A1**(대화·화면), **고운바탕**(노트 본문·AI 요약처럼 오래 읽는 글).
- 예약된 댓글은 점선 카드, 자동으로 온 댓글엔 ‘자동’ 표시가 붙어요.

## 확인이 필요한 점

- 철학자 답변과 자동 댓글은 실제 AI가 아니라 **미리 써 둔 시나리오 문장**이에요.
- 자동 댓글의 예약 시각과 ‘지금 받기’는 시연용이에요. 실제 OS 예약·알림 동작은 실기기 확인이 필요해요(설계서 32.3).
- **카뮈·시오랑 초상 사진은 사용권 확인이 필요**해요. 나머지 넷은 퍼블릭 도메인·CC0 자료예요.
- 설계서에서 정하지 않은 값은 자리표시로 뒀어요: `[기본 모델]`, `[모델 용량]`, `[구독료]`, `[크레딧]`.
- 논쟁 빈도·강도 설정은 '베타'(P1)로 표시했어요.
