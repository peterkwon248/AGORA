대표 흐름

S1 · 일상 감상으로 시작

광장에 노래 이야기 → 1~3명만 답함 → 서로 이어 말하기 → 잠잠해지면 대화 노트로 남길지 물어봄

S2 · @멘션으로 끼워 넣기

@ 입력 → 방 밖 철학자 → 이번만 / 고정 → 그 사람이 먼저 답함 → 임시는 답하고 퇴장

S3 · 방마다 다른 대화

새 단톡방 → 구성원 → 분위기 → 방마다 따로 기억하고, 다른 방 이야기는 꺼내지 않음

S4 · 가끔 생기는 논쟁

실제 이견이 있을 때만 → 빈도·강도는 방 설정 → ‘좀 더 부드럽게’ 한 번에 바로 완화

S5 · 한 날짜에 여러 노트

아침에 직접 쓴 노트 → 점심의 대화 노트 → 밤의 질문 노트. 셋 다 따로 고치고, 읽기 범위·댓글도 따로

S6–S7 · 사유 노트와 몇 시간 뒤의 말

허락한 노트에 시오랑 댓글 → 카뮈의 사유 노트 → 미리 써 둔 댓글·개인톡 → ‘왜 왔나요?’ · 조용한 시간
